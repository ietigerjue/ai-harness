# 失败恢复模板

> **用途**: 当 AI Harness 工作流中的任何环节失败时，使用此模板记录并恢复。目标是让项目不断档。
>
> **存放位置**: `05_可回溯记录/失败恢复记录/`

## 详细恢复流程

### FR-01: Codex 额度用完

- **触发条件**: Codex 返回额度耗尽或无法继续执行
- **应立即停止的行为**: 不要再尝试让 Codex 执行新任务
- **应记录的信息**: 当前项目状态、已完成 TASK 列表、未完成 TASK 列表、最近一次有效输出
- **下一步最小恢复动作**: ClaudeCode 读取项目记录文件和最近的 Handoff，接管项目
- **交接给哪个 Agent**: ClaudeCode
- **是否需要用户确认**: 否（自动交接）

---

### FR-02: ClaudeCode 上下文不足

- **触发条件**: 对话过长，ClaudeCode 开始丢失上下文或响应质量下降
- **应立即停止的行为**: 不要再追加新任务到当前会话
- **应记录的信息**: 当前状态、关键上下文摘要、未完成任务列表
- **下一步最小恢复动作**: 生成完整的 Handoff 文件 → 用户开启新会话 → 新会话读取 Handoff
- **交接给哪个 Agent**: ClaudeCode（新会话）
- **是否需要用户确认**: 否（但用户需要手动开启新会话）

---

### FR-03: 文件修改失败

- **触发条件**: 文件写入、Edit、删除操作报错
- **应立即停止的行为**: 停止对该文件的所有操作，不要反复重试
- **应记录的信息**: 目标文件路径、操作类型、错误信息、文件当前状态
- **下一步最小恢复动作**: 检查文件权限、文件是否被占用、路径是否正确 → 修复后重试一次
- **交接给哪个 Agent**: 同一 Agent 重试，若仍失败则交接
- **是否需要用户确认**: 若涉及权限问题，需要用户确认

---

### FR-04: 构建失败

- **触发条件**: 编译、打包、构建命令返回非零退出码
- **应立即停止的行为**: 停止构建流程，不要忽略错误继续
- **应记录的信息**: 构建命令、错误日志摘要、涉及的文件
- **下一步最小恢复动作**: 分析错误日志 → 定位问题文件 → 修复 → 重新构建
- **交接给哪个 Agent**: Codex（修复代码）
- **是否需要用户确认**: 否（除非是环境配置问题）

---

### FR-05: 测试失败

- **触发条件**: 测试用例未通过
- **应立即停止的行为**: 不要跳过失败的测试直接进入下一阶段
- **应记录的信息**: 失败的测试用例名称、断言错误、涉及的代码
- **下一步最小恢复动作**: 分析失败原因 → 修复代码或测试用例 → 重新运行测试
- **交接给哪个 Agent**: Codex
- **是否需要用户确认**: 否（除非需要修改测试预期）

---

### FR-06: 需求不清

- **触发条件**: 用户需求模糊、矛盾、或缺少关键信息
- **应立即停止的行为**: 不要猜测需求继续执行
- **应记录的信息**: 当前理解的需求、不清楚的点、需要用户澄清的问题列表
- **下一步最小恢复动作**: 列出需要澄清的具体问题 → 等待用户回复
- **交接给哪个 Agent**: ClaudeCode（整理问题）
- **是否需要用户确认**: 是（必须等用户回复）

---

### FR-07: Skill 不存在

- **触发条件**: 路由表指向的 Skill 未安装或不存在
- **应立即停止的行为**: 不要假设 Skill 存在或试图调用不存在的 Skill
- **应记录的信息**: 缺失的 Skill 名称、当前场景、影响
- **下一步最小恢复动作**: 使用备用方案 → 更新 Skill 路由表标记为"未确认"
- **交接给哪个 Agent**: 当前 Agent 使用备用方案
- **是否需要用户确认**: 否（但应在报告中告知用户）

---

### FR-08: 旧文件无法归类

- **触发条件**: 迁移或整理时发现无法按现有分类归类的文件
- **应立即停止的行为**: 不要强行归类或随意丢弃
- **应记录的信息**: 文件路径、文件内容摘要、无法归类的原因
- **下一步最小恢复动作**: 暂时放入 `99_迁移记录/未能归类内容.md` 中记录 → 标记待处理
- **交接给哪个 Agent**: Codex
- **是否需要用户确认**: 否（但应在迁移报告中列出）

---

### FR-09: design.md 未发现

- **触发条件**: 项目归档时找不到 design.md 文件
- **应立即停止的行为**: 不要捏造 design.md 的存在
- **应记录的信息**: 搜索范围、确认不存在的结论
- **下一步最小恢复动作**: 在归档总结中明确记录"未发现 design.md" → 继续归档
- **交接给哪个 Agent**: Codex
- **是否需要用户确认**: 否

---

### FR-10: 项目路径不存在

- **触发条件**: 引用的项目路径已失效、被移动、或被删除
- **应立即停止的行为**: 不要尝试写入失效路径
- **应记录的信息**: 失效路径、上次确认存在的日期、引用该路径的文件
- **下一步最小恢复动作**: 请求用户确认新路径 → 更新所有引用
- **交接给哪个 Agent**: ClaudeCode（确认新路径）
- **是否需要用户确认**: 是（必须等用户确认）
