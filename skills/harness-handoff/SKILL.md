# Agent Handoff — 双 Agent 交接

## 触发条件

- Codex 额度用完 → ClaudeCode 接力
- ClaudeCode 上下文不足 → 新会话继续
- 用户说"Handoff" / "交接" / "接力"
- 任务中断需要另一个 Agent 接手

## 前置条件

项目在进行中，项目记录文件存在。

---

## 执行流程

### Step 1: 确定交接双方

- 交出 Agent：当前执行者
- 接手 Agent：ClaudeCode 或 Codex（由场景决定）
- 用户可能直接指定

### Step 2: 读取项目当前状态

从项目记录文件中读取：
- 当前状态机位置
- 最近完成的 TASK
- 当前 NEXT_ACTIONS
- 最近的回滚点

### Step 3: 生成 Handoff 文件

在项目记录同目录创建 `Handoff-{项目名}-{日期}.md`：

```markdown

- 接手 Agent：
- 交接原因：
- 交接时间：
```

### Step 4: 更新项目记录

在项目记录文件的 Agent Handoff 记录表中追加一行。

### Step 5: 接手 Agent 确认

接手 Agent 读取 Handoff 文件后：
1. 确认当前状态机位置
2. 确认阻塞点是否仍然存在
3. 确认下一步任务是否可执行
4. 回复"已接收 Handoff，从 {状态} 继续"

---

## 常见交接场景

| 场景 | 交出 | 接手 | 原因 |
|---|---|---|---|
| Codex 额度用完 | Codex | ClaudeCode | 自动交接 |
| 上下文过长 | ClaudeCode | ClaudeCode | 新会话 |
| 任务类型切换 | 任一 | 另一 | 职责分工 |
| 用户主动要求 | 任一 | 指定 | 用户选择 |
