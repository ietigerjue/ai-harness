# 记忆库状态看板

## 触发条件

用户说"记忆库状态" / "status" / "看板" / "harness status"。

## 前置条件

记忆库已初始化。

---

## 输出内容

### 1. 项目总览

从 `00_总索引/项目总索引.md` 读取，按状态分组展示：

```
## 进行中项目
| 项目 | 领域 | 状态 | 最后更新 |
|---|---|---|---|
{active_projects}

## 已归档项目
| 项目 | 领域 | 归档日期 |
|---|---|---|
{archived_projects}
```

### 2. 最近活动

读取最近修改的 5 个项目记录文件，输出最近的操作。

### 3. 待归档项目

列出状态为 Review 或 Test 完成但尚未归档的项目。

### 4. 缺失 Skill

从 `00_总索引/Skill路由表.md` 读取标记为"⚠️ 未确认"的条目。

### 5. 记忆库健康度

```
## 记忆库健康检查
- 项目记录文件数：{N}
- 已归档项目数：{N}
- 孤儿文件：{N}（在项目记录目录中但未出现在项目总索引中）
- 未完成 Handoff：{N}
- 技术栈条目数：{N}
- 工作流沉淀条目数：{N}
```

### 6. 快速操作建议

```
## 建议操作
1. 项目 X 处于 Test 状态已 5 天，建议推进到 Review
2. 项目 Y 已完成超过 7 天但未归档
3. Skill Z 在路由表中标记为未确认，如需使用请先安装
```
