# 初始化 AI Harness 记忆库

## 触发条件

用户说"初始化记忆库" / "init harness" / "setup memory base" / 或在未初始化的目录中尝试使用其他 harness 命令。

## 前置条件

无。这是所有操作的入口。

---

## 执行流程

### Step 1: 确认安装位置

询问用户：

```
请选择记忆库安装位置：
1. 当前目录（推荐）
2. 自定义路径
```

如果用户选 2，让用户输入路径。**记忆库将在这个路径下创建一个文件夹**（默认名称 `Memory Base`，用户可自定义）。

### Step 2: 询问工作领域

询问用户：

```
你的 Agent（ClaudeCode / Codex）主要在哪些领域工作？

常见领域参考：
- 交易（股票、期货、加密货币等）
- 副业（自媒体、内容生产、独立产品、WebApp 开发等）
- 学校（科研、论文、课程项目等）
- 其他（请描述）

你可以选择多个领域，用逗号分隔。
例如：交易, 副业

如果都不匹配，请自定义你的领域名称。
```

**重要**：把用户说的领域名称原样作为 `01_项目记录/` 下的子目录名。

### Step 3: 询问 Agent 使用习惯

询问：

```
你的常用工作流是怎样的？

A. ClaudeCode 思考 + Codex 执行（双 Agent 标准模式）
B. 只用 ClaudeCode
C. 只用 Codex
D. ClaudeCode 为主，偶尔用 Codex
E. 其他（请描述）

这会决定记忆库中的 Agent 分工规则如何配置。
```

### Step 4: 创建记忆库目录结构

根据用户的回答，创建以下目录：

```
{记忆库根目录}/
├── 00_总索引/
├── 01_项目记录/
│   ├── {领域1}/
│   └── {领域2}/
├── 02_工作流沉淀/
├── 03_Skill产物/
├── 04_归档项目/
│   ├── WebApp/
│   ├── App/
│   ├── Skill/
│   ├── 嵌入式开发/
│   └── 机器学习/
├── 05_可回溯记录/
│   ├── 执行日志/
│   ├── 决策记录/
│   ├── 变更记录/
│   ├── 回滚点/
│   └── 失败恢复记录/
├── 06_评估与优化/
├── 07_模板库/
└── 99_迁移记录/
```

### Step 5: 写入种子文件

将以下文件写入 `00_总索引/`，内容从 `templates/` 和 `rules/` 目录读取并替换变量：

1. **README.md** — 记忆库总入口说明，含用户的工作领域列表
2. **MEMORY.md** — 记忆索引（初始为空，有模板说明）
3. **Agent分工说明.md** — 根据 Step 3 的 Agent 使用习惯配置
4. **项目状态机规则.md** — 项目阶段定义（通用，无需定制）
5. **权限与安全规则.md** — 操作权限分级（通用）
6. **回滚与版本记录.md** — 初始为空
7. **项目总索引.md** — 含用户领域分类的空表格
8. **领域分类索引.md** — 含用户自定义领域的说明
9. **Skill产物总索引.md** — 初始为空
10. **Skill路由表.md** — 场景→Skill 映射表（通用）

同时写入 `07_模板库/` 下的所有模板：
- 项目记录模板
- Agent-Handoff模板
- Done-Criteria模板
- NEXT_ACTIONS模板
- 失败恢复模板
- 项目归档模板

### Step 6: 写入 .harnessrc 配置文件

在记忆库根目录创建 `.harnessrc`：

```json
{
  "version": "1.0",
  "created": "{当前日期}",
  "domains": ["{领域1}", "{领域2}"],
  "agent_mode": "{A/B/C/D/E}",
  "memory_base_name": "{文件夹名}"
}
```

### Step 7: 写入 `.gitignore`

```gitignore
.harnessrc
.env
.env.*
*.local
```

### Step 8: 输出完成信息

```
✅ AI Harness 记忆库初始化完成！

记忆库位置：{路径}

你的工作领域：{领域列表}
Agent 模式：{模式}

已创建的目录结构：
- 00_总索引/（10 个规则和索引文件）
- 01_项目记录/{领域1}/、{领域2}/
- 02_工作流沉淀/
- 03_Skill产物/
- 04_归档项目/（5 种项目类型）
- 05_可回溯记录/（5 种记录类型）
- 06_评估与优化/
- 07_模板库/（6 个模板）
- 99_迁移记录/

下一步：
1. 对 ClaudeCode/Codex 说"新建项目 {项目名}"创建你的第一个项目记录
2. 项目记录会自动放在 01_项目记录/{你的领域}/
3. 项目推进过程中，Agent 会按状态机自动追踪进度
```

---

## 种子文件变量替换规则

所有模板和规则文件中的以下占位符需要替换：
- `{MEMORY_BASE_NAME}` → 用户选择的记忆库文件夹名
- `{DOMAINS}` → 用户选择的领域列表
- `{AGENT_MODE}` → 用户选择的 Agent 模式
- `{CREATION_DATE}` → 当前日期
- `{DOMAIN_LIST_MD}` → 格式化的领域列表（Markdown 表格行）
