## 3. 文件操作安全规则

### 3.1 覆盖保护

```
覆盖前必须：
1. 将原文件复制为 "{原文件名}.bak.{日期}"
2. 写入新内容
3. 验证新文件可读
4. 在变更记录中记录覆盖操作
5. 原文件备份保留至少 7 天
```

### 3.2 删除保护

```
删除前必须：
1. 向用户说明要删除的文件及原因
2. 列出这些文件是否被任何项目或索引引用
3. 等待用户明确回复"确认删除"
4. 删除后在变更记录中记录
5. 更新所有引用这些文件的索引
```

### 3.3 批量操作保护

```
批量操作前必须：
1. 生成完整的操作计划（列出每个文件的源路径和目标路径）
2. 说明操作原因
3. 等待用户确认
4. 操作完成后验证每个文件到位
5. 更新所有受影响的索引
```

## 6. 敏感信息保护

1. **环境变量**: 不得存入 Git 或记忆库明文
2. **API Key**: 不得出现在任何记录文件中
3. **密码/Token**: 不得出现在执行日志中
4. **个人信息**: 手机号、身份证、银行卡等不得存入记忆库

---

## 7. 违规处理流程

1. 发现违规操作（如 Agent 自行删除了文件）→ 立即记录到 `06_评估与优化/Harness问题复盘.md`
2. 评估影响范围
3. 如可能，从备份或 Git 历史恢复
4. 更新规则防止再次发生
